**Software Engineer who lives in GitHub.** I listen to what teams actually need, then make it happen: moving them to GitHub, fixing their pipelines, automating the rest. I still write the code too. 4+ years of .NET and Azure behind me, so I get both sides. Big AI enthusiast and sceptic in one: I love what it can do, and I still check its work.

📍 Poland · 🗣️ Polish (native), English (C1)

## 🛠️ What I do

- 🚚 Move teams to GitHub, from a handful of repos to 1,000+, without losing a single commit
- 🏢 Set up GitHub Enterprise to be secure by default and stay out of everyone's way
- ⚙️ Turn clunky old pipelines into fast GitHub Actions and automate the boring requests with IssueOps
- 🤝 Work closely with clients to find out what they really need, not just what they ask for
- 💻 Write real code too: C#, ASP.NET Core, Azure, SQL Server
- 🎤 Attend conferences, and sometimes speak at them
- 🎓 Collect certifications (GitHub and Azure) along the way
